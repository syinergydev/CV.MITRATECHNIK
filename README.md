# CV. Mitra Tehnik Indonesia — Website Demo

Website multi-halaman untuk CV. Mitra Tehnik Indonesia (bengkel permesinan logam, Sidoarjo). Dibuat sebagai konsep demo oleh SynergyDev. HTML, CSS, dan JavaScript statis, tanpa backend.

## Halaman
index.html (Beranda), tentang.html, layanan.html, produk.html, portofolio.html (filter + lightbox), kualitas.html (timeline proses), artikel.html + artikel/ (2 artikel), kontak.html (formulir RFQ → WhatsApp).

## Membuka lokal
Buka index.html di browser. Font dan GSAP dimuat dari internet.

## Deploy ke GitHub Pages
1. Buat repository, misalnya mitra-tehnik-indonesia.
2. Upload isi folder ke root repository (index.html harus di root).
3. Settings → Pages → Deploy from a branch, branch main, folder /(root).
4. Ganti USERNAME pada sitemap.xml dan robots.txt.
